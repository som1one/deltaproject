ТЗ: Платформа агентства блогеров для рекламы товаров маркетплейсов
1. Цель платформы
Создать автоматизированную систему, где:
блогеры привлекают работников по реферальной ссылке
работники ищут продавцов и закрывают сделки
продавцы покупают рекламу у блогеров
система автоматически считает сделки, комиссию и выплаты
Платформа должна минимизировать ручную работу.

2. Типы пользователей
На сайте должно быть 3 типа аккаунтов.
1. Работник (аутричер)
Его задача:
писать продавцам маркетплейсов
находить рекламодателей
создавать сделки

2. Блогер
Его задача:
делать рекламу
привлекать работников по реферальной ссылке

3. Администратор (основатель)
Функции:
контроль всех сделок
подтверждение клиентов
управление выплатами
управление блогерами

3. Регистрация
На сайте должна быть регистрация.
Поля:
имя
email / telegram
пароль
Выбор роли:
1 Блогер
2 Работник

Реферальная система
Каждый блогер получает:
site.com/ref/username
Если работник регистрируется по этой ссылке:
он автоматически привязывается к блогеру

сколько оплачено
сколько заработал

Создать новую сделку

выбранный блогер

Создать сделку

Подтверждена
Оплачена

Скрипты сообщений
На странице должен быть раздел:
Скрипты для переписки
Чтобы работник просто копировал текст.
